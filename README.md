# CachyCuts

A terminal UI for viewing and managing keyboard shortcuts on this machine (Hyprland keybindings, managed via the ML4W dotfiles framework).

## Status

Early scaffold. Currently just renders a placeholder screen.

## Stack

- Rust + [ratatui](https://ratatui.rs) + [crossterm](https://github.com/crossterm-rs/crossterm)

## Run

```sh
cargo run
```

Press `q` to quit.
